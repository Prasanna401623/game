# Loops - web builds

Published Ren'Py web exports, built and deployed separately from the `main`
branch's source. Not meant to be edited directly, republish by rebuilding
in the Ren'Py Launcher and copying the output here.

- `tracked/` - requires one of the 20 issued codes (TELEMETRY_REQUIRE_CODE = True)
- `open/` - no code required (not yet published)
